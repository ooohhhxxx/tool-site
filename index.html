核心功能

一个软件，搞定多种调试需求

🖥️

SSH 远程管理

  • 连接记录保存，账号密码加密存储，一键登录
  • 远程文件可视化浏览，路径栏可直接输入跳转
  • 支持多选批量上传，右键菜单下载 / 上传到当前目录
  • 内置交互终端：直接在终端区打字，Tab 补全、↑↓ 历史
  • 终端字号可缩放，支持一键保存终端输出
🔌

Modbus TCP 调试

  • 快速读写支持 01 / 03 / 05 / 06 功能码
  • 寄存器实时监控表，支持 01 / 02 / 03 / 04 四种区域
  • 连续地址自动合并读取，几百个点位轮询也不卡
  • 数值可切十进制 / 十六进制 / 有符号 16 位查看
  • 双击监控行即可改写数值，报文日志全程留痕
🔧

串口调试工具

  • 自动识别串口并显示设备描述，常用波特率齐全
  • HEX 发送 / 接收，自动校验十六进制格式
  • 接收编码可选 UTF-8 / GBK，中文设备不再乱码
  • 时间戳、收发字节统计、暂停显示
  • 发送内容支持 ↑↓ 回翻历史，重复下发不用重敲
🧩

插件扩展

  • 内置示例插件：批量命令、寄存器扫描、HEX 收发助手
  • 插件可自带操作界面，直接嵌在软件里运行
  • 支持启用 / 禁用 / 重载，任务可随时中断
  • 把插件文件放进用户目录即可自动识别
