v1.3.28 2026-11-02
修复
某些时候双击图标没反应，或者反过来开出了两个程序：用远程桌面、或在 Windows 上切换过用户之后，程序会以为「已经有一个在运行」然后悄悄退出，屏幕上什么都不说；换一个 Windows 用户时更糟——它认不出另一个用户已经开着，于是两个程序同时跑，抢着写同一份配置。现在这两种情况都会明确告诉你原因。
修复
多选上传遇到同名文件，会把前一份悄悄盖掉：不同目录下的两个 config.ini 会先后传到远端同一个路径，最后界面报「上传完成 2 个」，实际只剩一份内容。现在选好文件就会先问你；如果覆盖的是远端本来就有的文件，结果里也会注明覆盖了几个。
修复
系统加密不可用时，保存的密码其实是明文：那种情况下只能退回可逆编码（base64），一行就能还原，但以前存的时候不吭声、读的时候也不吭声。现在保存时终端里会说明，下次加载那条记录时状态栏还会再提示一次。
修复
插件打日志太猛时，界面会越用越卡：插件回调排进界面的队列以前没有上限，插件在循环里逐行打日志时，攒的比刷的快，内存和延迟只涨不降。现在队列有上限，丢掉的次数会在插件日志里说一声。
改进
更新提示框以前把整篇更新日志都塞进来：这次日志已经八百多字，1366×768 的机器上对话框会顶出屏幕，把「是 / 否」按钮推到看不见的地方。现在只显示几行摘要，完整日志到「关于」里看。
改进
Modbus 从站拒绝了请求，日志里只有一串英文：以前显示 Exception Response(144, 3, IllegalAddress)，看着像「读不到」，其实是地址不存在。现在直接翻成「地址不存在（设备上没有这个寄存器 / 线圈）」「数值超出范围」这类话，超时和从站无响应也分开说。
改进
另外几处收口：界面上改的设置如果没能写进配置文件（磁盘满、没权限），日志里会留一条，不再让你以为记住了；SSH 连接记录最多保留最近 50 条（以前只增不减），超出时会说明；「关于」窗口里的更新日志遇到控制字符不再显示成乱码。
v1.3.27 2026-11-01
修复
终端里一条颜色 / 光标控制序列正好被网络分块切断时，会显示成「[38;5;」这种残渣：前一块原样显示成半截序列，后一块又漏出「8m」。现在被切断的半截序列先攒着，等下一块补齐再一起剥掉；跨块的 \r\n 也并成一个换行，不再多出一个空行。攒着的尾巴超过 512 字符照旧放行，不会把显示卡住。
修复
串口接收区的时间戳取的是「刷到屏上」那一刻：界面积压时，一小时前进来的包显示的时刻是刚刚，看着像设备秒回。现在改在包到达的那一刻取值。
修复
SSH 连接记录经不起手工改动：读不懂的条目（手改坏的、缺字段的）以前在下次「保存配置」时被整体写回抹掉；端口手工写成数字时匹配不上，同一条记录会被存成两条；口令首尾的空格保存时被剪掉、连接时不剪，取出来已经不是原来输入的那个口令。现在读不懂的条目原样留在文件里，端口读进来就归一化，口令两边都按原文。
修复
Modbus 的端口和超时不做校验：0、70000 这类端口照样发给客户端，超时填错不吭声按 3 秒去连。现在值或范围不对会说清楚；自动重连撞上坏参数时，把原因写进状态栏并停下，等你改对再点连接，不再按错的值一直试。
修复
上传取消或断线后，远端会留下一份长度不对的半截文件：文件列表里看着像已经传上去了。现在改成先传 .part、整份到位再换成正式名字（和下载同一套做法）；换名失败不再报「上传失败」，会把留在远端的 .part 路径说出来，你还能自己救。
v1.3.25 2026-11-01
修复
点「取消」或断开之后，还在路上的那次连接会把你刚关掉的会话救活：晚到的成功结果照样写回界面，出现「显示已连接、终端却没反应」，多出来的网络会话也一直不关。现在连接结果带序号，过期的一律作废并关掉 socket（SSH、Modbus 各一处）。

修复
用记事本改过的配置文件读不出来：带 BOM 时整份参数（含窗口位置、大小）会被当成损坏退回默认值。现在和插件文件一样容忍 BOM。连接记录文件被改坏时也不再只给一个空白下拉框——会说明是整份损坏还是几条格式不对，其余记录照常可选。
优化
后台界面队列和串口重连链在异常路径上也照样排下一次，不会因为一次异常就断掉；拖动分栏之后不再往控制台甩 invalid command name。
优化
在线更新：已经下好的安装包在启动安装前先校验一次，不通过就重新下载，不会去装一个坏包；检查或下载线程没能起来时，状态栏写「检查未能开始 / 下载未能开始」，不再默默停在原地。

优化
