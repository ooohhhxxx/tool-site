终极调试工具
标准操作程序（SOP）

文件编号：SOP-UT-001 ｜ 版本：V1.0 ｜ 生效日期：2026-08-24 ｜ 编制：工具开发组

一、目的

为规范"终极调试工具"（以下简称"本工具"）的安装、配置与日常使用，确保操作人员能够正确、安全地完成 SSH 远程管理、Modbus TCP 通信调试与串口设备调试，降低误操作风险，提高排障效率，特制定本 SOP。

二、适用范围

  • 本工具的安装、部署与更新；
  • SSH 远程服务器管理与文件传输；
  • Modbus TCP 设备（PLC、仪表、传感器等）的在线调试；
  • 串口（RS232 / RS485 / USB 转串口）设备的通信调试。

三、运行环境要求

项目要求说明
操作系统Windows 10 / 11（64 位）不支持 macOS / Linux
运行依赖无安装包已内置运行环境，无需安装 Python
网络目标 SSH / Modbus 设备网络可达跨网段需先打通路由或 VPN
串口USB 转串口或原生串口驱动正常端口号可在设备管理器查看
磁盘空间≥ 100 MB—

四、安装与卸载

4.1 安装

  1. 从官网下载 UltimateTool.exe 安装包；
  2. 若杀毒软件（Defender / 360 / 火绒等）告警，先加入信任/白名单（本工具为个人免费软件，未购买数字签名，告警属误报）；
  3. 双击安装包，按向导提示"下一步"，可自行选择安装路径；
  4. 安装完成后勾选"运行 终极调试工具"，桌面将生成快捷方式。

4.2 卸载

控制面板 → 程序和功能 → 终极调试工具 → 卸载；或运行安装目录下的卸载程序。

五、SSH 远程管理操作流程

5.1 连接服务器

  1. 切换到"SSH 远程管理"标签页；
  2. 依次填写：主机（服务器 IP）、端口（默认 22）、用户名、密码；
  3. 点击"连接"，底部状态栏显示"SSH: 已连接 x.x.x.x"即为成功；
  4. 成功后左侧自动加载远程根目录文件列表，右侧终端显示欢迎信息。

5.2 保存与使用历史记录

  1. 填写账号密码后点击"保存配置"，记录将加密保存在本机；
  2. 下次从"历史记录"下拉框选择记录，账号密码自动填充，一键连接；
  3. 选中记录后点击"删除记录"可移除。

5.3 文件上传 / 下载

  1. 在左侧列表双击文件夹进入，"上级目录"返回；
  2. 上传：点击"上传"，选择本地文件，将上传到当前远程目录，右上角进度条显示进度；
  3. 下载：选中文件后点击"下载"，选择本地保存位置；
  4. 传输完成后点击"刷新文件"核对结果。

5.4 终端命令

  1. 在下方输入框输入命令，回车执行；
  2. Tab 键自动补全常用命令；↑ / ↓ 键翻找历史命令；
  3. "清屏"可清空终端显示。
⚠️ 在终端执行 rm、reboot 等破坏性命令前，务必反复确认目标路径与服务器，防止误操作生产环境。

六、Modbus TCP 调试操作流程

6.1 建立连接

  1. 切换到"Modbus TCP 调试"标签页；
  2. 填写设备 IP、端口（Modbus 默认 502）、超时时间（默认 3000ms）；
  3. 点击"连接"，状态栏显示"Modbus: 已连接"即成功。

6.2 功能码速查表

功能码含义操作类型
01读线圈读
02读离散输入读
03读保持寄存器读
04读输入寄存器读
05写单个线圈写（1=ON，0=OFF）
06写单个寄存器写
15写多个线圈写
16写多个寄存器写

6.3 快速读写

  1. 在"快速读写"区选择功能，填写地址与值/数量；
  2. 点击"执行"，结果输出到右侧报文日志。

6.4 寄存器实时监控

  1. 选择类型、填写起始地址与数量，点击"添加监控"；
  2. 点击"刷新"读取一次当前值；勾选"自动轮询"可按间隔持续读取（建议间隔 ≥ 500ms）；
  3. 修改数值：单击选中表格某一行，在下方"新值"框输入后点击"写入修改"；
  4. 选中行后点击"删除"可移除监控点。
🚨 安全红线：对运行中的设备（尤其是控制物理动作的 PLC）写入任何寄存器前，必须与现场人员确认地址含义，擅自写入可能导致设备动作或生产事故！

七、串口调试操作流程

7.1 打开串口

  1. 切换到"串口调试工具"标签页，点击"刷新端口"；
  2. 在"端口"下拉框选择目标串口（如 COM3）；
  3. 按设备铭牌/手册设置：波特率（常用 9600 / 115200）、数据位 8、停止位 1、校验 None；
  4. 点击"打开串口"，状态栏显示端口名与波特率即成功。

7.2 发送数据

  1. 在发送框输入内容；勾选"HEX 发送"后可发送十六进制数据（如 01 03 00 00 00 02）；
  2. 勾选"自动换行"会在末尾附加换行符；
  3. 点击"发送数据"或按回车发送。

7.3 接收数据

  1. 接收区实时显示收到的数据；
  2. "HEX 显示"切换十六进制视图；"显示时间戳"便于分析通信周期；
  3. 左下方统计收/发字节数；"清空接收"可清零重新统计。
⚠️ 若串口列表为空：检查 USB 转串口驱动是否安装（设备管理器有无黄色感叹号）；若提示"串口被占用"，请关闭其他占用串口的软件（串口助手、PLC 编程软件等）。

八、常见故障与排除

故障现象可能原因处理方法
软件被杀毒告警/删除未签名个人软件误报杀毒软件隔离区恢复，添加信任/白名单后运行
SSH 连接失败IP/端口/密码错误；服务器未开 SSH；防火墙拦截逐项核对参数；确认服务器放行 22 端口
文件上传失败远程目录无写权限 / 磁盘满换有权限的目录（如 /tmp）；清理磁盘
Modbus 连接被拒绝设备未上电 / IP 错误 / 端口非 502ping 设备 IP；确认设备已启用 Modbus TCP 服务
Modbus 读取超时地址/数量超范围；设备忙核对设备手册地址表；减小数量；增大超时
串口列表为空驱动未装或线未接安装 USB 转串口驱动；重插后在设备管理器确认
串口打开失败（占用）端口被其他软件占用关闭串口助手/编程软件等后重开
接收乱码波特率/校验与设备不一致按设备参数逐项对齐；改用 HEX 显示查看原始数据

九、安全与注意事项

  • 本工具将 SSH 密码加密保存在本机，请勿在公共电脑上保存敏感服务器记录；
  • Modbus / 串口写操作为实时不可逆动作，执行前必须二次确认；
  • 生产高峰期避免进行大文件传输与批量写入操作；
  • 调试结束后，养成点击"断开"/"关闭串口"释放连接的习惯；
  • 本工具完全免费，不收集任何用户数据。
