调试工具
标准操作程序（SOP）

文件编号：SOP-UT-001 ｜ 版本：V1.3.0 ｜ 生效日期：2026-10-29 ｜ 编制：工具开发组

一、目的

为规范"调试工具"（以下简称"本工具"）的安装、配置与日常使用，确保操作人员能够正确、安全地完成 SSH 远程管理、Modbus TCP 通信调试与串口设备调试，降低误操作风险，提高排障效率，特制定本 SOP。

二、适用范围

  • 本工具的安装、部署与更新；
  • SSH 远程服务器管理与文件传输；
  • Modbus TCP 设备（PLC、仪表、传感器等）的在线调试；
  • 串口（RS232 / RS485 / USB 转串口）设备的通信调试；
  • 通过插件扩展的批量运维、寄存器扫描等辅助功能。

三、运行环境要求

项目要求说明
操作系统Windows 10 / 11（64 位）不支持 macOS / Linux
运行依赖无安装包已内置运行环境，无需安装 Python
网络目标 SSH / Modbus 设备网络可达跨网段需先打通路由或 VPN
串口USB 转串口或原生串口驱动正常端口号可在设备管理器查看
显示建议 1366×768 及以上已适配高分屏缩放，字体清晰不发虚
磁盘空间≥ 100 MB安装包约 20 MB，安装后约 65 MB

四、安装、升级与卸载

4.1 安装

  1. 下载 UltimateTool.exe 安装包；
  2. 若杀毒软件（Defender / 360 / 火绒等）告警，先加入信任/白名单（本工具为个人免费软件，未购买数字签名，告警属误报）；
  3. 双击安装包，按向导提示"下一步"，可自行选择安装路径；
  4. 安装完成后勾选"运行 调试工具"，桌面将生成快捷方式。

4.2 升级

  1. 推荐：打开软件 → 插件页 →「检查更新」，检测到新版本后一键下载安装（V1.2.0 起支持）；
  2. 也可以直接下载新版本安装包并运行，安装到相同目录即可覆盖升级，无需先卸载；
  3. 连接历史记录、插件启停状态保存在用户目录（~/.ssh_gui_history.json、~/.ssh_gui_plugins.json），升级后自动保留；
  4. 窗口大小与位置记录在 ~/.ssh_gui_ui.json，如界面错乱可删除该文件后重启。

4.3 卸载

控制面板 → 程序和功能 → 调试工具 → 卸载；或运行安装目录下的卸载程序。

五、SSH 远程管理操作流程

5.1 连接服务器

  1. 切换到"SSH 远程管理"标签页；
  2. 依次填写：主机（服务器 IP）、端口（默认 22）、用户名、密码；
  3. 目标设备输出中文时如出现乱码，把"编码"改为 GBK 后再连接（默认 UTF-8）；
  4. 点击"连接"，底部状态栏显示"SSH: 已连接 x.x.x.x"即为成功；连接过程中可点"取消"中断。

使用私钥登录（免密）：点密码框右侧的 🔑 按钮选择私钥文件（如 id_rsa、id_ed25519），按钮变蓝表示已启用，此时密码框自动禁用，直接点"连接"即可。

💡 用完后在 🔑 按钮上点右键可清除私钥、改回密码登录。若私钥本身有 passphrase，本工具暂不支持输入，请先用 ssh-keygen -p 去掉口令或改用密码登录。

5.2 保存与使用历史记录

  1. 填写账号密码后点击"保存配置"，记录加密保存在本机；
  2. 下次从"历史记录"下拉框选择记录，账号密码自动填充，一键连接；
  3. 选中记录后点击"删除记录"可移除。

5.3 浏览与维护远程目录

  1. 连接成功后自动列出根目录，目录优先排列，双击文件夹进入；
  2. 顶部"路径"栏可直接编辑：输入 /opt/app 后回车跳转，也支持 ~（家目录）和相对路径（如 ../log）；
  3. 点击"上级目录"或路径栏左侧的 ↑ 返回上一层；
  4. 右键空白处或选中文件，可执行：打开/进入、下载到本地、上传到这里、复制路径、刷新。

文件维护（均在右键菜单中，操作后列表自动刷新且保留选中项）：

操作说明
新建文件夹选中某个目录时建在它下面，否则建在当前目录
重命名输入新名称即可，名称中不能带 /
修改权限输入八进制权限，如 644、755、600
删除文件需在确认框点"是"；目录需手动输入目录名确认，且只能删除空目录
🚨 删除不可恢复！确认框里会显示完整路径，请逐字核对。删除正在运行的程序或配置前，先备份或确认可重建。

5.4 文件上传 / 下载

  1. 上传：点击"上传"，在文件选择框中按住 Ctrl 可多选，文件将上传到当前远程目录，右上角显示"第 N/M 个 + 百分比 + 已传/总大小"；
  2. 下载：选中文件后点击"下载"（或直接双击该文件、右键选"下载到本地"），再选择本地保存位置；
  3. 传输完成后列表自动刷新，状态栏显示落盘路径；
  4. 若目标目录无写权限，换用有权限的目录（如 /tmp、~/）。

5.5 终端操作

  1. 连接成功后直接在终端区域内打字即可，无需另找输入框；回车即执行；
  2. Tab 键补全文件名/命令，↑ / ↓ 翻找历史命令；
  3. Ctrl + 鼠标滚轮 可放大 / 缩小终端字号，长命令和小屏都方便；
  4. 终端底部工具条提供「Ctrl+C（中断）」「清屏」「保存日志」；右键菜单可复制、粘贴、全选、保存终端输出；
  5. 按 Ctrl+F 打开查找框：输入关键字即高亮全部匹配并显示命中数量，按回车或 ↓ 跳到下一处、Shift+回车 或 ↑ 跳上一处，Esc 关闭并清除高亮；
  6. 向上滚动查看历史输出时，新输出不会把视图强行拽回底部；滚回最底部后恢复自动跟随。

⚠️ 在终端执行 rm、reboot 等破坏性命令前，务必反复确认目标路径与服务器，防止误操作生产环境。
💡 排障取证时用「保存日志」把整段终端输出存成 txt，比截图更便于检索和转发给同事。

六、Modbus TCP 调试操作流程

6.1 建立连接

  1. 切换到"Modbus TCP 调试"标签页；
  2. 填写设备 IP、端口（Modbus 默认 502）、超时时间（默认 3000ms，网络差可加大）；
  3. 点击"连接"，状态栏显示"Modbus: 已连接"即成功。

6.2 功能码与软件入口对照

功能码含义本软件中的入口
01读线圈快速读写 / 监控（类型选"线圈"）
02读离散输入监控（类型选"离散输入"）
03读保持寄存器快速读写 / 监控（类型选"保持寄存器"）
04读输入寄存器监控（类型选"输入寄存器"）
05写单个线圈快速读写 / 监控行"写入修改"
06写单个寄存器快速读写 / 监控行"写入修改"

6.3 快速读写

  1. 在"快速读写"区选择功能，填写地址与值/数量；
  2. 地址支持十六进制写法，如 0x10 等同 16；数值同样支持 0x 前缀；
  3. 读取数量范围 1～125（受 Modbus 单帧上限约束），超出会直接提示；
  4. 点击"执行"，请求与结果输出到右侧"报文日志"。

6.4 寄存器实时监控

  1. 选择类型、填写起始地址与数量，点击"添加监控"；重复添加不会产生重复行；
  2. 点击"刷新"读取一次；勾选"轮询"并按间隔（默认 1000ms，建议 ≥ 500ms）持续读取；
  3. 显示格式：右上"数值"下拉可切 十进制 / 十六进制 / 有符号(16位)，"地址"下拉可切十进制 / 十六进制 —— 只改变显示，不会重新读设备；
  4. 修改数值：双击表格某一行（或选中后在下方的"新值"框输入，回车生效），点击"写入修改"；
  5. 选中行后点击"删除"可移除监控点；点"导出CSV"把整张表存成 CSV（UTF-8 带 BOM，Excel 直接打开不乱码），含地址、类型、显示值、原始值与导出时间。
  6. 监控点位会自动保存，下次打开软件仍在列表里，无需重新添加。
💡 监控点位很多时，软件会把地址连续、功能码相同的点合并成一次读取，几百个点位也能流畅轮询；数值没有变化的行不会重复刷新，界面不会闪。
🚨 安全红线：对运行中的设备（尤其是控制物理动作的 PLC）写入任何寄存器前，必须与现场人员确认地址含义，擅自写入可能导致设备动作或生产事故！

七、串口调试操作流程

7.1 打开串口

  1. 切换到"串口调试工具"标签页，点击"刷新"重新枚举端口；
  2. 在"端口"下拉框选择目标串口，列表会显示设备描述（如 COM3 - USB-SERIAL CH340），便于区分多个转换器；
  3. 按设备铭牌/手册设置：波特率（常用 9600 / 115200）、数据位 8、停止位 1、校验 None；
  4. 点击"打开串口"，状态栏显示端口名与波特率即成功。

7.2 发送数据

  1. 在发送框输入内容；勾选"HEX 发送"后可发送十六进制数据（如 01 03 00 00 00 02，空格可有可无）；HEX 格式非法时会提示，不会发出错误数据；
  2. "自动换行"会在末尾附加换行符；快捷按钮「回车 / 换行 / 空格」可发送单个控制字符；
  3. 在发送框按 ↑ / ↓ 可回翻最近 50 条发送内容，重复下发不用重新敲；
  4. 点击"发送数据"或按回车发送。

7.3 接收数据

  1. 接收区实时显示收到的数据；
  2. 勾选"HEX"切换十六进制视图（按字节空格分隔），"时间戳"便于分析通信周期；
  3. 设备输出中文乱码时，把"编码"切到 GBK（默认 UTF-8）—— 已按字符边界解码，切换后不会再出现半截字符；
  4. 数据刷得太快看不清时勾选"暂停"，接收不中断、只是不刷新界面，取消勾选后继续显示；
  5. 左下方统计收/发字节数；"清空接收"可清屏并清零统计。
  6. 勾选"记录"（与 Modbus 页共用同一个开关）会把收发内容写入 ~/调试工具日志/日期.log，按天分文件，便于事后追溯。
⚠️ 若串口列表为空：检查 USB 转串口驱动是否安装（设备管理器有无黄色感叹号）；若提示"串口被占用"，请关闭其他占用串口的软件（串口助手、PLC 编程软件等）。

八、插件功能

8.1 插件页构成

  • 左侧上方为插件列表（插件名 / 版本 / 状态 / 说明）；
  • 左侧下方为所选插件的"动作"列表，双击动作或点"运行所选动作"执行；
  • 右侧上方是插件自带的操作界面，下方是插件运行日志（红字为错误）。

8.2 内置插件

插件用途
SSH 批量执行把多条命令一次下发到当前服务器，逐条显示结果与退出码
Modbus 寄存器扫描按块读取一段地址，快速找出有效点位
串口 HEX 收发助手按帧收发十六进制数据，可定时循环发送并等待应答

8.3 启用、停用与重载

  1. 选中插件后点"启用/加载"或"禁用"，状态即时生效并会记住；
  2. 插件更新文件后点"重载"（或"全部重载"）即可加载新代码，无需重启软件；
  3. 插件任务卡住时点"停止任务"中断；
  4. 点"打开插件目录"可查看插件文件所在位置。
💡 用户插件目录为 ~/.ssh_gui_plugins，优先级高于内置插件；同名插件放在这里即可覆盖内置版本。

九、软件更新

本工具内置在线更新：软件会自己发现新版本并提示，确认后自动下载安装包，覆盖安装后连接记录与插件配置全部保留，不需要手动去网站找安装包。

9.1 检查更新的两种方式

方式触发时机说明
自动检查每次启动软件约 5 秒后后台静默进行，不阻塞使用。只有发现新版本才弹窗；没有更新或网络不通都不会打扰操作
手动检查插件页 →「检查更新」随时可点，检查结果显示在按钮右侧
💡 自动检查只读取一个几 KB 的版本清单，不下载安装包，不影响启动速度。确需关闭，可在启动前设置环境变量 ULTIMATE_TOOL_NO_UPDATE=1。

9.2 一键更新步骤

  1. 切换到"插件"标签页，在"插件管理"框底部找到更新区；
  2. 点"检查更新"（若已发现新版本，按钮会直接显示"立即更新"）；
  3. 显示新版本后点"立即更新"，进度条会显示下载百分比与已下载/总大小；
  4. 下载完成后弹窗询问是否安装：选"是"，软件自动退出并启动安装程序，按提示完成安装后重新打开即可；
  5. 选"否"，安装包会保留在本地临时目录，稍后双击该文件同样可以完成更新。
⚠️ 安装过程会关闭本软件，正在执行的插件任务、Modbus 自动轮询、串口接收都会中断。请先结束手上的调试工作，再点更新。

9.4 更新会影响什么

  • 会保留：服务器连接记录与密码、插件启停状态、窗口大小与位置（均保存在用户目录下的配置文件中，覆盖安装不影响）；
  • 会中断：更新时软件退出，正在运行的插件任务、自动轮询、串口接收都会停止，需重新开启；
  • 需要权限：安装到 Program Files 时 Windows 会弹出 UAC 确认框，属正常现象；
  • 首次升级：V1.1.x 及更早版本没有更新模块，需手动安装一次 V1.2.0，从 V1.2.0 起才能收到自动提醒。

界面字号过小/过大高分屏缩放差异终端内用 Ctrl+滚轮调整；其他区域跟随系统缩放设置
窗口尺寸异常显示分辨率变化删除 ~/.ssh_gui_ui.json 后重启，窗口恢复默认尺寸

十一、安全与注意事项

  • 本工具将 SSH 密码加密保存在本机，请勿在公共电脑上保存敏感服务器记录；
  • Modbus / 串口写操作为实时不可逆动作，执行前必须二次确认；
  • 生产高峰期避免进行大文件传输与批量写入操作；
  • 调试结束后，养成点击"断开"/"关闭串口"释放连接的习惯；
  • 插件与本工具拥有相同的设备访问权限，只安装来源可信的插件；
  • 本工具完全免费，不收集任何用户数据。
